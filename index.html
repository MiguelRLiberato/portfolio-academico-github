Projeto simples desenvolvido para praticar HTML, CSS, JavaScript e controle de versão com GitHub.

Sobre o projeto

Este site foi criado como atividade acadêmica para demonstrar a publicação de um projeto no GitHub e o uso de recursos como repositórios, commits e ramificações.

Tecnologias utilizadas

  • HTML5 para estrutura da página
  • CSS3 para estilização
  • JavaScript para interação
  • GitHub para versionamento e hospedagem do código

Interação

Clique no botão para testar uma funcionalidade em JavaScript.
