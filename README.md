# Meu Portfólio Acadêmico

Projeto simples desenvolvido para praticar:

- HTML
- CSS
- JavaScript
- GitHub
- Controle de versão
- Commits
- Branches

## Objetivo

Demonstrar o uso prático do GitHub em uma atividade acadêmica, utilizando um projeto web simples como exemplo de versionamento e organização de código.

## Como executar

Abra o arquivo `index.html` em qualquer navegador moderno.
